## 🛠️ Technical Stack

### Core Technologies
- **Framework**: React Native 0.73.2
- **Platform**: Expo SDK 50
- **Language**: TypeScript 5.3
- **Navigation**: React Navigation 6.x

### UI & Styling
- **Components**: React Native Paper 5.11
- **Icons**: @expo/vector-icons 14.0
- **Gradients**: expo-linear-gradient 12.7
- **Animations**: react-native-reanimated 3.5, react-native-animatable 1.3

### Forms & Validation
- **Form Management**: Formik 2.4
- **Validation**: Yup 1.3
- **HTTP Client**: Axios 1.6

### User Experience
- **Haptics**: expo-haptics 12.7
- **Safe Area**: react-native-safe-area-context 4.8
- **Gestures**: react-native-gesture-handler 2.14
