# Assets Folder

## Resume File

Place your actual resume PDF file here as `resume.pdf`.

The current `resume.pdf` is a placeholder. Replace it with your actual resume.

### Instructions:
1. Create your resume as a PDF file
2. Name it `resume.pdf`
3. Place it in this `assets` folder
4. The app will automatically use it for the "View Resume" button

The resume will be downloadable on both web and mobile platforms.
